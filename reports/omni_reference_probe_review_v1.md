# 官方 Omni-MoE 固定探针审阅

这些是固定SHA的官方315M参考权重输出，不是本项目已训练出的模型。用于验证评估路径、建立具体对照，不是标准benchmark、未见测试集或总能力评分。来源见 `data/manifests/omni_reference_model.json`，原始输出和WAV见 `models/03_omni_moe/reference_evaluation/`。

| 输入/题目 | 实际观察 | 限制 |
|---|---|---|
| T2A中文春天一句话 | 回答一句相关文字，46帧/3.68秒语音；ASR归一化16字符全部一致 | 只证明该短例文字/语音一致，不证明自然度或通用质量 |
| T2A英文咖啡一句话 | 输出长段落，未遵守简短指令；256步音频19.84秒被截断 | 原CER35.7%包含截断，不能全算发音错误 |
| 相同英文咖啡，上限512 | 文字完全相同、前248帧codes完全相同；增至291帧/23.28秒，未触上限 | ASR CER仍25.6%，剩余尾部缺失不能仅归于预算；可能有语音漏说/提前停止或ASR遗漏 |
| A2A中文语音问春天 | 输入只含真实音频特征占位，没有把问题转写文本喂给模型；回复相关，129帧/10.32秒；ASR40字符一致 | 此例不能概括所有语速、噪声或问题 |
| A2A英文语音问天空 | 文字提到散射，但也错误地把阳光说成几种气体；音频达256步上限 | 文字知识正确性与ASR一致性是两回事；CER15.8%仍包含截断/识别因素 |
| I2T水果篮 | 图像实际是苹果、香蕉、橙子；输出仅提对橙子，漏掉另两类，加入草莓/柠檬/葡萄/菠萝/蓝莓 | 原始图像已人工像素核对；两张图不能推算总体视觉准确率 |
| I2T熊猫举牌 | 正确识别熊猫，但没有读出“你好”，编造V字样及其他不受图像支持的细节 | 识别主体与OCR是不同子任务；不能只抓住“熊猫”就宣布图像问答成功 |

所有生成使用相同固定版官方模型和tokenizer，文本是带固定seed的官方采样，非greedy。I2T两项保留了达到256步上限的原始文字/音频；没有通过删除错误句改善展示。长音频预算的控制实验、音频依赖失败与复测见 `docs/debug/009_omni_generation_and_audio_io.md`。

对我们后续训练的意义：先确认数据/模态确实进入模型和loss正确，再分别观察任务正确性、语音对文字的忠实度、终止、遗忘与资源。CE下降、音频可解码、官方参考能输出声音，都不能替代这些检查。现阶段不因此随意增大模型参数，也不把参考失败包装成本项目已经超越它的证据。
