# 真实Hybrid第一个batch：从文本到目标标签

对应正式配置 `models/02_hybrid_moe/configs/hybrid_sft_official_mini_2ep_v1.json`。仅CPU重建，未新增训练；顺序来自真实seed和sampler。

输入和labels均为 `[16, 768]`；logits按模型定义为 `[16, 768, 6400]`。
本批12,288个输入位置，实际有7,818个next-token监督标签，与正式第1步metrics一致。

`input_ids`包含用户、助手、特殊token与padding；`labels=-100`的位置不进入CE。
`logits[:, :-1]`预测`labels[:, 1:]`，因此位置j的非忽略label由位置j-1的logits预测；没有把输入原位置直接当成答案。
先对有效assistant目标求CE均值，再加MoE辅助损失；此配置累积1，一批就是一次optimizer更新。
