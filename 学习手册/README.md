# 从这次真实实验学会训练模型

其他电脑请先按[分享版指南](../SHARING_GUIDE.md)建立自己的环境。教学工具会自动定位仓库根目录；小样本随仓库提供，模型权重按需下载，不依赖作者本机的数据盘。

这是公开分享版；原实验的本机路径只作为历史记录。先读本页，再顺序完成各章的练习。这里用实际模型、原始数据、113,082次更新和真实故障讲解；不会把失败结果包装成训练成功。

## 你手里到底有什么

主案例是205,623,072参数的Hybrid MoE：官方198M SFT权重 → 替换六层注意力 → 官方mini数据两轮全参数SFT。训练预算完成，评估结果与生成样例已记录；这条分支**没有Hybrid预训练**。普通198M从零预训练在13,209步被用户停止，SFT未开始。Omni/Dense/dLM只有各自标注的预检或研究资料，不能算正式训练完成。

读完材料不能自动证明掌握。每章都需要你先预测、再观察实际文件、最后解释差异；第10章给出可操作验收题与参考答案。能独立完成这些任务，比背下命令更接近训练工程师的能力。

## 只读学习命令

先按[分享指南](../SHARING_GUIDE.md)建立环境，再在你clone的仓库根目录执行：

```bash
python -B tools/study_minimind.py summary
python -B tools/study_minimind.py replay --step 12000
python -B tools/study_minimind.py sample --index 51023
```

CPU推理和梯度追踪命令见第10章。学习工具没有optimizer和训练恢复入口，不会续跑已停止的普通MoE。输出目录必须是`学习手册/实操输出`下的**新目录**，避免覆盖你的答案。模型坏答案也会原样保存。

## 原始证据保持在哪里
