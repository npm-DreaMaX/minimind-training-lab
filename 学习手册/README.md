# 从这次真实实验学会训练模型

这是一套围绕真实205M Hybrid MoE实验的分步课程。01–10章已经按入门顺序重写：先讲清概念，用小数字手算，再进入真实源码与记录，最后通过操作和诊断验收。第02章保留逐位置数据讲解，并接入后续课程。

**看完十个链接不等于学会。** 本课程的要求是你能解释、计算、定位源码、核对实际结果，并面对新问题提出检查。现成答案用于核对，不代替自己动手。

## 从哪里开始，需要哪些东西？

先读01，不需要先会深度学习。02讲编号和标签；03从向量、点积开始解释结构；04从一个参数开始算学习过程。遇到没学过的术语，在本章首次出现的位置先看具体例子，不要求先背公式。

其他电脑按[分享指南](../SHARING_GUIDE.md)克隆到自己的目录。仅阅读与标准库机制演示不需要GPU、模型权重或完整语料；样本解码需要CPU依赖；完整205M CPU推理/梯度检查再按需下载权重。当前本机交付根目录是`D:\minimind`，但课程命令不依赖这个盘符。

## 学习证据分三层，不能混用

**机制演示**使用很小的数字，让你算清原理；它不代表正式模型的性能或训练结果。新工具[lesson_examples.py](../tools/lesson_examples.py)只用标准库，不加载大模型，支持attention、delta、moe、optimizer、resume和真实records重算。

**真实历史**包括113,082次更新、验证、GPU记录、checkpoint审计、失败日志。命令重放只是读已发生的事件；没有记录的逐步激活不会被虚构出来。

**完整模型观察**使用205M CPU forward/backward或生成，模型结构完整，教学trace只取128位置前缀。它没有optimizer更新，不能拿短前缀loss冒充全量验证成绩。

开始时可以在自己仓库根目录运行：

```bash
python -B tools/lesson_examples.py attention
python -B tools/lesson_examples.py optimizer
python -B tools/lesson_examples.py resume
python -B tools/study_minimind.py summary
```

前两种机制中出现的参数和学习率是教学数值；正式训练配置没有改变。自己的练习与输出写新目录，完整操作见第10章。

## 主案例的真实边界

205,623,072参数；官方198M SFT权重转换，六层新Gated DeltaNet随机初始化，随后两轮全参数SFT。**没有Hybrid预训练。** 已完成两轮SFT，训练记录、评估结果和生成样例已公开。普通MoE从零分支在13209步停止；Omni、Dense、dLM和RL按各目录标注，不算已完成正式训练。

这套材料能支撑对这个真实案例的系统学习与可复核实操。它不能替代后续从零完整训练、分布式、正式RL或全Omni阶段的独立经验，不会承诺“看完自动成为算法工程师”。
